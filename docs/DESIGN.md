# DESIGN: Nagrik Mitra

> Source of truth for visuals is the **Stitch export**. This file defines tokens and rules so Antigravity and Stitch stay aligned. If Stitch output differs, Stitch wins for layout and this file wins for naming and behavior.

## Principles
- Voice-first: the mic is the hero of the home screen.
- Low literacy friendly: big type, icons with labels, minimal fields.
- Trust: calm civic look, clear status colors, official tone in PDF.
- Mobile-first, one primary action per screen.

## Typography
- Devanagari + Latin: **Noto Sans Devanagari** + **Inter** (UI numerals).
- Body 16 px minimum, headings 22 to 28 px, line height 1.5 (Devanagari needs room).

## Screens
1. **Language select / Home:** logo, language toggle (मराठी | हिन्दी | EN), giant mic button, "or take a photo" button, "view public dashboard" link.
2. **Listening:** pulsing mic, live transcript, stop button, type instead link.
3. **Review:** editable transcript, photo thumbnail, "Analyze" button.
4. **Result:** category chip with icon, department card, severity badge, summary, documents checklist (checkboxes).
5. **Location:** Leaflet map with draggable pin, "use my location" button, detected address and ward, name + phone inputs.
6. **Success:** reference number, PDF preview/download button, WhatsApp share, track link, QR optional.
7. **Dashboard:** ward filter, status filter, map with clustered pins, ward table with counts, recent complaints list.
8. **Complaint detail / track:** timeline of status events, map pin, PDF link.

## Components
MicButton, LanguageToggle, CategoryChip, DepartmentCard, DocumentChecklist, LocationPicker, StatusBadge, WardStatsTable, ComplaintCard, Timeline, Stepper (3 steps: Speak, Verify, Submit), Toast.

## Category icons
pothole = road/alert, garbage = trash, ration_card = id-card.

## PDF design (Marathi/Hindi)
- A4, header: "प्रति, <department name>, पुणे" (To, Department, Pune).
- Fields: Reference no, date, subject line, citizen name/phone, address and ward, lat-long, body paragraph (formal, in citizen language), documents enclosed list, signature block, footer "Generated by Nagrik Mitra".
- Static map snippet is optional (stretch). Include a Google Maps/OSM link text instead.
- Font: bundled Noto Sans Devanagari, 12 pt body.

## Motion
Mic pulse animation, subtle fade on result card. Respect reduced motion.
